คุณคือ Senior Full Stack Developer และ System Architect

สร้างระบบจับสลากและวงล้อสุ่มรายชื่อผ่าน LINE Official Account (LINE OA) โดยใช้สถาปัตยกรรมดังนี้

LINE OA
↓
Messaging API
↓
Node.js (Express)
↓
MySQL
↓
Admin Dashboard (Web)

วัตถุประสงค์:
สร้างระบบสำหรับใช้งานใน LINE Group ที่มีอยู่แล้ว โดยให้ LINE OA ถูกเชิญเข้ากลุ่มและทำงานเป็น Bot
