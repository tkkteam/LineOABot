# คู่มือการดูแลระบบ Oracle Cloud และ LineOABot 🚀

คู่มือฉบับนี้รวบรวมคำสั่งที่จำเป็นสำหรับการดูแลเซิร์ฟเวอร์ (Oracle Linux) และระบบบอท (Docker) เพื่อให้คุณสามารถดูแลระบบได้ด้วยตัวเองในระยะยาวครับ

> [!IMPORTANT]
> คำสั่งทั้งหมดด้านล่างนี้ จะต้องรันผ่านหน้าต่าง SSH (เช่น หน้าจอดำ CMD ของ Windows) โดยล็อกอินด้วยสิทธิ์ user `opc` ครับ

---

## 1. การจัดการเซิร์ฟเวอร์พื้นฐาน (Server Management)

**อัปเดตระบบปฏิบัติการ (OS Update)**
ควรทำเดือนละ 1-2 ครั้ง เพื่อรับแพตช์รักษาความปลอดภัยใหม่ๆ ทำให้เซิร์ฟเวอร์ปลอดภัยจากการถูกแฮ็ก
```bash
sudo dnf update -y
```

**รีสตาร์ทเซิร์ฟเวอร์ (Reboot)**
ใช้เมื่อต้องการเริ่มระบบใหม่ทั้งหมด (ระบบ Docker ของเราตั้งค่าไว้แล้วว่าให้รันขึ้นมาเองอัตโนมัติหลังจากเปิดเครื่อง)
```bash
sudo reboot
```

**ดูการใช้ทรัพยากรเครื่อง (CPU / RAM)**
เพื่อเช็คว่าเครื่องทำงานหนักไปไหม หรือ RAM เต็มหรือไม่ (เมื่อดูเสร็จ ให้กดปุ่ม `q` หรือ `Ctrl+C` เพื่อออก)
```bash
htop
```
*(หากรันไม่ได้ ให้ติดตั้งก่อนด้วยคำสั่ง `sudo dnf install htop -y`)*

**ดูพื้นที่ฮาร์ดดิสก์ (Disk Space)**
เช็คว่าฮาร์ดดิสก์ใกล้เต็มหรือยัง
```bash
df -h
```

## 2. การจัดการระบบบอท (Docker Compose)

> [!NOTE]
> ทุกครั้งที่จะจัดการระบบบอท คุณต้องเข้าไปที่โฟลเดอร์โปรเจกต์ก่อนเสมอด้วยคำสั่ง:
> `cd ~/LineOABot`

**ดูสถานะว่าระบบทำงานอยู่ไหม**
เช็คว่ามีส่วนไหนดับไปบ้าง (ดูช่อง Status ควรจะเป็น Up ทั้งหมด)
```bash
sudo docker compose ps
```

**รีสตาร์ทระบบบอทใหม่ (Restart)**
ใช้เมื่อระบบค้าง บอทไม่ตอบ หรือมีการแก้โค้ดภายใน
```bash
sudo docker compose restart
```

**อัปเดตระบบเมื่อมีการแก้ไฟล์ `.env`**
หากคุณแก้ไฟล์ `.env` แค่กด restart จะไม่ทำงาน ต้องใช้คำสั่งนี้เพื่อให้ระบบอ่านค่าใหม่เข้าไป:
```bash
sudo docker compose -f docker-compose.prod.yml up -d
```

**ดู Log ข้อผิดพลาด (สำคัญมากเวลาบอทพัง)**
ถ้าบอทไม่ทำงาน ให้ดูข้อความแจ้งเตือน (Log) ของ Backend เพื่อหาสาเหตุ (กด `Ctrl+C` เพื่อหยุดดู)
```bash
sudo docker logs line-lottery-backend -f
```

## 3. การอัปเดตระบบเมื่อมีการแก้โค้ด (ผ่าน GitHub Actions)

เมื่อคุณแก้ไขโค้ดและ Push ขึ้น GitHub จนระบบ **GitHub Actions** ทำการ Build Image เสร็จเรียบร้อยแล้ว ให้รันคำสั่งเหล่านี้ที่เซิร์ฟเวอร์ Oracle เพื่ออัปเดตระบบ:

```bash
# 1. เข้าไปที่โฟลเดอร์โปรเจกต์
cd ~/LineOABot

# 2. ดึง Image เวอร์ชันใหม่ล่าสุดที่ GitHub Actions เพิ่ง Build เสร็จ
sudo docker compose -f docker-compose.prod.yml pull

# 3. สั่งรันระบบ (Docker จะสลับเอา Image ตัวใหม่ขึ้นมาทำงานแทนให้เอง)
sudo docker compose -f docker-compose.prod.yml up -d

# 4. ลบไฟล์ Image เวอร์ชันเก่าที่ไม่ได้ใช้แล้วทิ้ง (ป้องกันฮาร์ดดิสก์เต็ม)
sudo docker image prune -f
```
*(💡 **หมายเหตุ:** คุณต้องรันคำสั่ง `git pull` เพิ่มเติมเฉพาะตอนที่คุณมีการแก้ไขโครงสร้างไฟล์ `docker-compose.prod.yml` เท่านั้น ถ้าแก้แค่โค้ดแอปพลิเคชัน รันแค่คำสั่งด้านบนก็เพียงพอแล้วครับ)*

## 4. การสำรองข้อมูล (Backup)

การสำรองข้อมูลของระบบนี้แบ่งเป็น 2 ส่วนสำคัญ คือ **ฐานข้อมูล** และ **รูปภาพสลิป/โปรไฟล์**

### 4.1 สำรองข้อมูลฐานข้อมูล (Database)
ใช้คำสั่งนี้เพื่อดึงข้อมูลทั้งหมดออกมาเป็นไฟล์ชื่อ `backup.sql`
```bash
sudo docker exec line-lottery-mysql mysqldump -u root -p'รหัสผ่านของคุณ' line_lottery > ~/LineOABot/backup.sql
```
> [!WARNING]
> รหัสผ่านที่ใช้ ต้องเป็นรหัสผ่านที่ฝังอยู่ในฐานข้อมูลก้อนปัจจุบันนะครับ (หากไม่แน่ใจหรือลืม ให้ใช้คำสั่ง `sudo docker inspect line-lottery-mysql | grep MYSQL_ROOT_PASSWORD` เพื่อดูรหัสผ่านก่อนครับ)

### 4.2 สำรองไฟล์รูปภาพสลิป (Images)
รูปสลิปและสลิปอัปโหลดต่างๆ สำคัญพอๆ กับฐานข้อมูล ใช้คำสั่งนี้บีบอัดโฟลเดอร์รูปภาพให้เป็นไฟล์ `.tar.gz` 
```bash
sudo tar -czvf ~/LineOABot/uploads_backup.tar.gz ~/LineOABot/backend/uploads
```

*(เมื่อสำรองข้อมูลทั้ง 2 ส่วนบนเซิร์ฟเวอร์เสร็จ คุณสามารถใช้คำสั่ง `scp` ในหน้าต่าง CMD ของคอมพิวเตอร์ที่บ้าน เพื่อดาวน์โหลด 2 ไฟล์นี้ไปเก็บสำรองไว้ในคอมพิวเตอร์ของคุณได้เลยครับ)*

## 5. การบำรุงรักษาและแก้ปัญหาทั่วไป (Troubleshooting)

**เคลียร์พื้นที่ขยะของ Docker**
เมื่อใช้งานหรืออัปเดตระบบบ่อยๆ Docker จะสร้างไฟล์ขยะสะสม คำสั่งนี้จะลบไฟล์ (Images/Containers) ที่ไม่ได้ใช้งานทิ้ง เพื่อคืนพื้นที่ฮาร์ดดิสก์ให้ Oracle
```bash
sudo docker system prune -a -f
```

**แก้ปัญหาบอทเซฟรูปสลิปไม่ได้ (Permission Denied)**
หากย้ายเซิร์ฟเวอร์ หรือสร้างโฟลเดอร์ใหม่ แล้วบอทเซฟสลิปไม่เข้า ให้รันคำสั่งนี้เพื่อปลดล็อกสิทธิ์:
```bash
sudo chmod -R 777 ~/LineOABot/backend/uploads
```
